# v8 plan: one home for everything pic writes

Working plan for `container-bootstrap-8`. Delete this file when the branch
merges; the reference is `pi-container/docs/configuration.md` (paths) and
`operations.md#moving-from-v7` (migration).

## Decided

| Question | Decision |
|---|---|
| Root | `~/.pic`, or `PIC_HOME` |
| Default profile | `$PIC_HOME/config`; only `~/.pic/config` keeps the default names |
| Other profiles | `$PIC_HOME/profiles/NAME` by convention; `PI_CONFIG_DIR` still takes any path |
| Backups, fleet data | `$PIC_HOME/backups`, `$PIC_HOME/fleet` (fleetd reads `PIC_HOME`) |
| Lock | `$PIC_HOME/lock`; two roots don't serialize image changes against each other |
| `overrides.env` | Read at runtime; `# pic overrides v1` header; `PI_BACKUP_DIR` and `PI_ENV_FILE` only; env vars win |
| v7 paths | `run.sh`, `clear.sh`, `pic serve` exit 2 and name `pic migrate` |
| Prompts | Only in `pic migrate`; it exits early if `$PIC_HOME` exists |
| v7 extra profiles | Moved on request, after `clear.sh nuke profile` (their names hash the path) |
| Moves | `mv`, same filesystem only; keys are never copied |
| E2E profile | `$PIC_HOME/profiles/e2e-test` (cleanup: `e2e-test2`) |

## Done on Linux

`names.sh` path helpers, `migrate.sh`, the `overrides.env` reader, the v7-path
refusal, the `~/.pic` mount refusal, `clear.sh list` for moved default-profile
volumes, fleetd and `pi-ctr` `PIC_HOME`, `mac-e2e.sh`, and the docs. Unit and
fake-CLI tests cover each.
